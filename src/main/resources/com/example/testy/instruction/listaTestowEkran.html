Okno lista testów

Okno listy testów zawiera pola takie jak:

  • Listę testów dostępnych dla użytkownika. Każdy test posiada przycisk "Szczegóły" który wyświetla szczegóły konkretnego testu.
  • Sekcję z filtrami takimi jak:
    • "Nazwa testu" pozwalającym filtrować test po nazwie.
    • "Kategoria" pozwalającym filtrować test po kategori.
    • "Ilość pytań" pozwalającym filtrować test po ilości pytań.
    • "Ilość podejść" pozwalającym filtrować test po ilości podejść.
    • "Właściciel" pozwalającym filtrować testy po testach użytkownika lub innych użytkowników.
  • Przycisk "Filtruj" który wyświetla listę testów z zastosowanymi filtrami podanymi przez użytkownika.
  • Przycisk "Resetuj filtry" który wyświetla pełną listę testów oraz przywraca filtry do wartości domyślnych.
  • Przycisk "Wróć" który powoduje przeniesienie użytkownika poprzedniego okna.
